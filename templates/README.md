# Versioned geometric templates

| Files | Consumers / meaning |
|---|---|
| `curves3.json`, `curves3_comparison.json`, `source3.npy` | Original 81-point source, frame/groups and short-curve comparison; structured/core samplers |
| `patches4.json`, `source4.csv` | Six fitted R4 patches and original 61-point source; core sampler |
| `circle.json`, `parabola.json`, `groups81.json` | Distillation starting model, grouping, exception lineage |

Do not edit these during a run. Models generated by distillation belong beside the
corresponding output coordinates. Original source hashes and zero-based assignments
must remain consistent. A template is not a partition-ratio certificate.
