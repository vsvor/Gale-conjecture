# Local experimental outputs

Use a fresh child directory for each run. Contents here are ignored by Git except
this guide and AGENTS.md. `scripts/run_experiment.py` writes provenance and captures
stdout/stderr; `docs/EXPERIMENT.md` describes the scientific report to complete.

Do not edit canonical code while an experiment is running. Do not delete failed or
neutral outputs merely to leave only successes. Promote selected compact results to
versioned examples only after explicit review, input/output hashes and verification.
