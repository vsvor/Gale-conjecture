# Additional experiment-directory guidance

The root AGENTS.md still applies. Outputs are data, not alternate editable source trees.
Run commands from the canonical repository with scripts/run_experiment.py. Use distinct
folders/seeds, a fixed source revision and the authorized total worker/time budget.
Do not treat --allow-long as authorization. Never turn a timeout into a mathematical
answer. Complete the run's EXPERIMENT.md with failures, both bounds and verification.
Do not promote, overwrite, publish or clean old outputs without an explicit task.
