# Historical source documentation

These files are the earlier package READMEs and original agent template, retained as
provenance rather than current setup instructions. They describe original directory
layouts and past experiments; some relative paths and named test counts refer to their
separate archives, not this consolidated tree. They were not silently rewritten to make
past results look newly reproduced.

Use root README.md and docs/development.md for current commands. Use validation/README.md
for tests actually run on this assembly. `SOURCE_MANIFEST.json` records imported-file
provenance. There is one working copy of each engine/helper; bulk historical logs and
all earlier archive versions are not duplicated here.
